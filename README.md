# Пелагия

Процедурный подводный мир в одном HTML-файле (около 33 КБ). WebGL2, без движка, библиотек, текстур, моделей и звуковых файлов: всё создаётся кодом при загрузке.

## Что внутри

- рельеф дна из шума, песок и скалы, каустика
- заросли ламинарии и морская трава (инстансинг, покачивание в вершинном шейдере)
- затонувший корабль, кораллы, камни
- косяки рыб, манты, медузы
- лучи света с поверхности, взвесь, пузыри
- процедурный звук (Web Audio)

## Запуск

Откройте `index.html` в браузере с поддержкой WebGL2. Сборка не нужна.

## Управление

- Компьютер: WASD — плыть, мышь — смотреть, E / Q — вверх / вниз, Shift — быстрее
- Телефон: левая половина экрана — плыть, правая — смотреть
- «Тур» — автоматический облёт, «Качество» — плотность растительности

Идея навеяна демо Abyssal Garden; код написан с нуля и с ним не связан.
